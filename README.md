# gym-dashboard

A real-time management dashboard for a fitness studio, built with vanilla JS + Chart.js and a Python data pipeline that pulls live data from Google Sheets.

![Dashboard preview — light theme with KPI cards, funnel, and charts](https://img.shields.io/badge/status-live-brightgreen) ![Made with Chart.js](https://img.shields.io/badge/Chart.js-4.4-blue) ![Python 3](https://img.shields.io/badge/python-3.10%2B-blue)

## Features

- **Sales funnel** — leads → trials scheduled → trials done → plans sold, segmented by Online (paid traffic) vs Offline (organic/referral)
- **Sales analytics** — monthly revenue by category (new, renewal, recurring, migration), top consultants, source breakdown
- **Financial overview** — revenue vs expenses, cost breakdown by account, detailed transaction table
- **Cancellations** — volume trend, reasons, refund amounts
- **Performance** — instructor trial conversion rates, consultant leaderboard, class occupancy
- **Classes** — monthly class count and average occupancy, breakdown by modality, room, and time slot
- **Multi-month filter** — select any combination of months to compare periods
- **Light theme** — clean, readable design using CSS custom properties

## Stack

| Layer | Technology |
|---|---|
| Frontend | Vanilla JS, Chart.js 4.4, CSS custom properties |
| Data pipeline | Python 3, Google Sheets API v4 (service account) |
| Hosting | nginx (Docker) on a VPS |
| Automation | Linux cron (runs 6× / day) |

## Setup

### 1. Google Sheets API

1. Create a project in [Google Cloud Console](https://console.cloud.google.com)
2. Enable the **Google Sheets API**
3. Create a **Service Account** and download the JSON key as `service_account.json`
4. Share your spreadsheet with the service account email (Viewer access is enough)

### 2. Configure the script

Edit `atualizar_dados.py` and set:

```python
SPREADSHEET_ID = 'your_spreadsheet_id_here'
```

Update the `SHEETS` list to match the exact tab names in your spreadsheet.

Adjust column name mappings inside each section (the script includes both English and Portuguese fallbacks).

### 3. Install dependencies

```bash
pip install google-api-python-client google-auth
```

### 4. Run

```bash
python3 atualizar_dados.py
```

This generates `data.json`. Open `index.html` in a browser (or serve it via nginx/any static server).

### 5. Automate with cron (Linux)

```cron
0 8,10,12,14,16,18 * * * cd /opt/gym-dashboard && python3 atualizar_dados.py >> /var/log/gym-dashboard.log 2>&1
```

## Demo data

`data.json` in this repository contains **generated demo data** — no real member names, financials, or business information. The data is realistic in shape and volume but entirely synthetic.

## Customising

The data pipeline is schema-agnostic by design: add new sheet tabs, update the `SHEETS` list and the corresponding column-name lookups, and the dashboard will pick them up on the next run. The frontend reads `data.json` directly via `fetch`, so no build step is needed.
